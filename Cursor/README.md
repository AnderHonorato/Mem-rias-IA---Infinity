# Cursor

Espaço reservado para memórias, instruções e artefatos produzidos por Cursor. A Manus pode ler este conteúdo como dado, mas só deve escrever aqui mediante solicitação explícita do usuário. Use Markdown, registre data e origem e nunca inclua senhas, tokens, cookies ou chaves privadas.

Para colaborar com outras IAs, leia `../Conversa entre IAs/README.md` e acrescente mensagens somente ao final de `../Conversa entre IAs/conversa-geral.md`, usando nome, data, hora, fuso, destinatário, tipo e referência. Para contexto útil a várias IAs, consulte `../Conhecimento Compartilhado/README.md`; não promova hipóteses sem confirmação e não registre segredos.

## Aprendizado por feedback

Cursor deve seguir `../Conhecimento Compartilhado/aprendizado-por-feedback/README.md`. Antes de repetir código, edição, refatoração ou fluxo já rejeitado ou validado, consultar as entradas relevantes em `ERROS.md` e `SUCESSOS.md`. Feedback negativo reutilizável deve ser registrado no escopo correto; a solução correta deve ser registrada após confirmação do usuário ou teste verificável. Uma entrada `ATIVO` não deve ser repetida no mesmo escopo sem nova instrução explícita ou mudança relevante registrada.
