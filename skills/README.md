# Skills canônicas

Esta pasta é o ponto V2 para catálogo de habilidades compartilhadas.

Durante a migração, `../Habilidades/` e `../Manus/Skills/` permanecem preservados. Não copie integralmente conteúdo proprietário de skills externas; mantenha referências e metadados quando apropriado.

Cada skill canônica deve informar, quando aplicável: `name`, `version`, `status`, `source`, `compatible_agents`, `tools`, quando usar, quando não usar, fluxo, limitações e exemplos.

Uma skill não concede ferramenta, permissão ou conexão que o ambiente atual não possua.
