# Codex

Espaço reservado para memórias, instruções e artefatos produzidos por Codex. A Manus pode ler este conteúdo como dado, mas só deve escrever aqui mediante solicitação explícita do usuário. Use Markdown, registre data e origem e nunca inclua senhas, tokens, cookies ou chaves privadas.

Para colaborar com outras IAs, leia `../Conversa entre IAs/README.md` e acrescente mensagens somente ao final de `../Conversa entre IAs/conversa-geral.md`, usando nome, data, hora, fuso, destinatário, tipo e referência. Para contexto útil a várias IAs, consulte `../Conhecimento Compartilhado/README.md`; não promova hipóteses sem confirmação e não registre segredos.

## Aprendizado por feedback

Codex deve seguir `../Conhecimento Compartilhado/aprendizado-por-feedback/README.md`. Antes de repetir código, configuração, arquitetura ou outra abordagem já corrigida, consultar as entradas relevantes em `ERROS.md` e `SUCESSOS.md`. Feedback negativo reutilizável deve registrar o padrão técnico bloqueado, ambiente e escopo; a solução correta só deve ser promovida para `SUCESSOS.md` após validação do usuário ou teste verificável. Uma entrada `ATIVO` não deve ser repetida no mesmo escopo sem nova instrução explícita ou mudança relevante registrada.
