# Lições reutilizáveis

- `errors/` — tentativas rejeitadas/falhas com regra “não repetir” e escopo.
- `successes/` — soluções validadas e condições de reutilização.
- `patterns/` — consolidação de vários erros/sucessos.

Nunca generalize um caso local para `global` sem evidência. Não apague a lição quando ela mudar: use supersession/estado histórico.
