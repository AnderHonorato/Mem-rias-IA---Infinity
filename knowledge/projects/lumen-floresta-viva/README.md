# Lúmen — Floresta Viva

## Objetivo confirmado
Criar uma página web imersiva, criativa, interativa e animada, inspirada na imagem enviada pelo usuário. A direção visual usa floresta noturna, lagoa turquesa, árvore luminosa, lua crescente e portal verde-violeta. A experiência inclui os rótulos “Criar imagem”, “@ VEED Video Generator” e “@ Creative Claw”.

## Escopo entregue
- Site de uma página, responsivo, com cena Three.js, interação de cursor/toque, parallax, partículas, portal e efeito de água.
- Tela de entrada, conteúdo narrativo, fragmentos do ateliê, controles de som, movimento reduzido e intensidade.
- Arte panorâmica própria gerada a partir da referência e armazenada nos arquivos do projeto.

## Limites conhecidos
Os nomes “@ VEED Video Generator” e “@ Creative Claw” aparecem como referências/fragments criativos na interface; não há integrações de API desses serviços. A publicação pública não foi solicitada nem executada.
