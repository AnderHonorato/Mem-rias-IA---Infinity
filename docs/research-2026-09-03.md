- OWASP Agentic Security / ASI06: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/

## Decisão

Adotar adaptadores pequenos por plataforma e uma única fonte canônica em `knowledge/`. Usar `AGENTS.md` como mapa curto, progressive disclosure para reduzir contexto, frontmatter + JSON Schema 2020-12 para contratos, proveniência inspirada em W3C PROV e trust boundaries explícitas para reduzir memory/context poisoning.

A implementação evita depender de um mecanismo proprietário único: Markdown permanece a fonte humana/canônica e índices JSON são materializações regeneráveis.
