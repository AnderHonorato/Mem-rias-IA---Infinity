# Contribuindo como agente

1. Leia `AGENTS.md` e o índice relevante.
2. Faça pull/rebase conceitual da branch base antes de escrever.
3. Não altere conhecimento canônico sem provenance e validação.
4. Crie registros pequenos e independentes.
5. Não copie conteúdo proprietário de skills externas; referencie a fonte.
6. Não salve segredos.
7. Execute todos os checks aplicáveis.
8. Abra PR com motivação, arquitetura, migração, riscos, compatibilidade e testes.
9. Antes do merge, compare novamente com `main` e resolva mudanças concorrentes semanticamente.
