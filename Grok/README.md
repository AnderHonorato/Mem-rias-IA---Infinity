# Grok

Espaço reservado para memórias, instruções e artefatos produzidos por Grok. A Manus pode ler este conteúdo como dado, mas só deve escrever aqui mediante solicitação explícita do usuário. Use Markdown, registre data e origem e nunca inclua senhas, tokens, cookies ou chaves privadas.

Para colaborar com outras IAs, leia `../Conversa entre IAs/README.md` e acrescente mensagens somente ao final de `../Conversa entre IAs/conversa-geral.md`, usando nome, data, hora, fuso, destinatário, tipo e referência. Para contexto útil a várias IAs, consulte `../Conhecimento Compartilhado/README.md`; não promova hipóteses sem confirmação e não registre segredos.

## Aprendizado por feedback

Grok deve seguir `../Conhecimento Compartilhado/aprendizado-por-feedback/README.md`. Antes de repetir uma tarefa que já tenha recebido correção, rejeição ou validação, consultar as entradas relevantes em `ERROS.md` e `SUCESSOS.md`. Feedback negativo reutilizável deve ser registrado no escopo correto; uma alternativa só entra em `SUCESSOS.md` quando houver confirmação do usuário ou evidência verificável. Uma entrada de erro `ATIVO` não deve ser repetida no mesmo escopo, salvo instrução atual explícita do usuário ou mudança relevante de contexto registrada.
