# backend-seguro

Usar para Node.js/TypeScript, Python, Go, Java, .NET e equivalentes quando o foco estiver na lógica de servidor, contratos, segurança, confiabilidade, observabilidade ou desempenho; combinar com uma skill de banco quando houver modelagem ou migração relevante e com full stack quando também houver interface completa.
