# midia-visual-profissional

- **Origem:** Habilidade especializada adicionada ao ambiente
- **Disponibilidade:** depende de a habilidade ou plugin correspondente estar instalado no ambiente da IA.

## Finalidade

Criar, editar, converter, otimizar e verificar imagens ou vídeos para web, redes sociais, anúncios, apresentações e produtos digitais. Usar para geração visual por IA, remoção de fundo, recorte, redimensionamento, composição, thumbnails, banners, sprites, GIF/WebP, montagem, legendas, transcodificação, áudio, codecs e exportação em lote; usar ferramentas visuais dedicadas para criação/edição e FFmpeg/ImageMagick para processamento determinístico.
