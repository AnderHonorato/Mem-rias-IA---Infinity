# fullstack-producao

- **Origem:** Habilidade especializada adicionada ao ambiente
- **Disponibilidade:** depende de a habilidade ou plugin correspondente estar instalado no ambiente da IA.

## Finalidade

Construir, ampliar ou corrigir uma aplicação completa envolvendo interface, servidor, autenticação, banco de dados, integrações, configuração e entrega executável. Usar para SaaS, dashboards, portais, e-commerce, CRUDs e produtos web de ponta a ponta quando frontend e backend precisam funcionar juntos; não usar para uma alteração isolada de somente interface, API ou banco quando uma skill específica cobrir melhor o pedido.

## Como usar

Use esta habilidade somente quando a finalidade acima corresponder ao pedido. Antes de agir, leia a versão instalada ou oficial da habilidade no ambiente atual e siga suas dependências, permissões e limites.

> Esta ficha registra descoberta e roteamento. Ela não substitui o pacote oficial nem concede acesso a ferramentas, contas ou serviços externos.
