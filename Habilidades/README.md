# Habilidades compartilhadas

Esta pasta reúne habilidades que podem ajudar qualquer IA que trabalhe neste repositório. Cada habilidade ou ficha deve ter finalidade própria e pode usar subpastas para referências, scripts e recursos relacionados.

## Regra de uso para todas as IAs

1. Depois de ler o README raiz e as instruções da sua própria área, consulte [INDEX.md](INDEX.md) quando a tarefa puder se beneficiar de uma habilidade especializada.
2. Leia apenas a habilidade necessária para o pedido atual. Não carregue todo o catálogo sem necessidade.
3. Prefira a habilidade mais específica e use o menor conjunto suficiente. Combine habilidades somente quando os domínios realmente se cruzarem.
4. Uma habilidade orienta o trabalho, mas não substitui o pedido do usuário, as regras do ambiente, segurança, permissões ou necessidade de confirmação antes de ações externas.
5. Confirme se a habilidade, plugin, ferramenta ou dependência está disponível no ambiente atual. Uma ficha de catálogo não instala nem concede acesso automaticamente.
6. Skills personalizadas podem guardar o conteúdo completo. Para habilidades padrão, baixadas ou de plugins, esta pasta mantém fichas de descoberta e roteamento; use o pacote oficial instalado para obter as instruções completas.
7. Nunca registre senhas, tokens, cookies, chaves privadas, códigos de recuperação ou outros segredos.

## Organização

## Manutenção

Ao adicionar ou atualizar uma habilidade, preserve sua origem, data e finalidade; atualize [INDEX.md](INDEX.md); evite duplicatas; e não altere uma habilidade pertencente à área nominal de outra IA sem autorização explícita do usuário.
