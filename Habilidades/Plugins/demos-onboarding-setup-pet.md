# demos:onboarding-setup-pet

- **Origem:** Plugin demos
- **Disponibilidade:** depende de a habilidade ou plugin correspondente estar instalado no ambiente da IA.

## Finalidade

Run a short, visual onboarding flow to choose a built-in ChatGPT Work pet or create a personalized custom pet. Use when helping someone set up a pet. Start with the labeled built-in lineup in a raw-HTML @visualize surface, defer pet management to the canonical `$pets` skill in `openai/oai-maintained-plugins/plugins/pets`, and finish with a one-at-a-time GIF carousel instead of a sprite sheet. Adapt the conversation to what the user has already shared.

## Como usar

Use esta habilidade somente quando a finalidade acima corresponder ao pedido. Antes de agir, leia a versão instalada ou oficial da habilidade no ambiente atual e siga suas dependências, permissões e limites.
