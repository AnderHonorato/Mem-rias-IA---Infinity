# Índice de habilidades

**Atualizado em:** 2026-08-28

Consulte somente as habilidades relacionadas à tarefa. A disponibilidade real depende do ambiente de cada IA.

## Personalizadas

- [astrologo-oracular](Personalizadas/astrologo-oracular/SKILL.md) — Interpretar astrologia, signos, mapa natal, sinastria, trânsitos, tarô e simbolismo espiritual; responder dúvidas sobre Candomblé e Umbanda com respeito às diferenças entre tradições; criar conceitos e imagens místicas quando solicitados. Usar em consultas esotéricas, leituras simbólicas, estudos religiosos afro-brasileiros e direção visual relacionada.

## Padrao

- [answers-charts](Padrao/answers-charts.md) — Use when a chart would communicate a categorical comparison, trend, composition, or numeric relationship more clearly than prose.
- [answers-images](Padrao/answers-images.md) — Use when retrieved images would visually ground or meaningfully improve an answer.
- [answers-learning](Padrao/answers-learning.md) — Use when the user explicitly requests flashcards, an objective multiple-choice knowledge quiz, or pronunciation help and an interactive learning widget would improve the answer.
- [control-browser](Padrao/control-browser.md) — Control a browser for authenticated or public web tasks requiring live site state or interaction. For selecting a sign-in method or entering sign-in credentials, use only the advertised `browserAuth` capability. For public lookups, use web search first; NEVER fall back to Browser if search fails. Use Browser only when successful search lacks necessary data or direct site interaction is required. ALWAYS prefer applicable plugins; NEVER fall back to Browser if one is unavailable or fails.
- [documents](Padrao/documents.md) — Create, edit, redline, and comment on `.docx`, Word, and Google Docs-targeted document artifacts inside the container, with a strict render-and-verify workflow. Use `render_docx.py` to generate page PNGs (and optional PDF) for visual QA, then iterate until layout is flawless before delivering the final document.
- [imagegen](Padrao/imagegen.md) — Generate or edit raster images when the task benefits from AI-created bitmap visuals such as photos, illustrations, textures, sprites, mockups, or transparent-background cutouts. Use when Codex should create a brand-new image, transform an existing image, or derive visual variants from references, and the output should be a bitmap asset rather than repo-native code or vector. Do not use when the task is better handled by editing existing SVG/vector/code-native assets, extending an established icon or logo system, or building the visual directly in HTML/CSS/canvas.
- [openai-docs](Padrao/openai-docs.md) — Use for Codex models/pricing, scheduled tasks, skills, settings, setup, troubleshooting, customization, automations, and self-knowledge—including 'you,' 'your,' 'this app,' or 'this coding agent' when they refer to Codex—and for OpenAI APIs/products and ChatGPT Work. Also use for model choice/migration, prompting, SDKs, Responses, Realtime, agents, evals, and Chat/Work/Codex comparisons. Do not use for generic app/software tasks that merely mention Codex.
- [pdf](Padrao/pdf.md) — Read, create, inspect, render, and verify PDF files where visual layout matters, including fillable AcroForms. Use Poppler rendering plus Python tools such as reportlab, pdfplumber, and pypdf for generation and extraction.
- [personal-context](Padrao/personal-context.md) — Use this skill when either of the following situations are true. Continuity related: the user explicitly or implicitly refers to prior conversation state, shared work, an earlier artifact, decision, preference, constraint, attempt, or progress item, including elliptical phrases like continue, next, again, still, update it, compare it, same as before, my axes, or our plan. Decision related: a specific unseen prior preference, constraint, history item, or attempt would materially change a concrete choice, and not be a marginal improvement. Reading and tool discovery are only a check; after loading, discover and load Personal Context's full instructions, and call personal_context.search only if they apply. Use it before another tool when the prior state changes retrieval or judgment. Skip first-turn generic facts, generic personal-domain advice, visible-context-complete work, and current-source-only tasks.
- [plugin-creator](Padrao/plugin-creator.md) — Create and scaffold plugin directories for Codex with a required `.codex-plugin/plugin.json`, optional plugin folders/files, valid manifest defaults, and personal-marketplace entries by default. Use when Codex needs to create a new personal plugin, add optional plugin structure, generate or update marketplace entries for plugin ordering and availability metadata, or update an existing local plugin during development with the CLI-driven cachebuster and reinstall flow.
- [Presentations](Padrao/presentations.md) — Read, create or edit PowerPoint or Google Slides decks. Use for presentation, slide deck, PowerPoint, PPT, PPTX, or Google Slides requests.
- [resolve-recipients](Padrao/resolve-recipients.md) — Resolve and verify the correct people before sending Slack messages, emails, invitations, meeting requests, calendar events, or other person-directed actions. Use whenever a request names, implies, or describes one or more recipients, especially with first names, duplicate names, nicknames, project groups, phrases such as “everyone,” or ambiguous references such as “the one I work with.” Search relevant communication and calendar history, compare candidate identities, and ask for clarification instead of silently guessing.
- [skill-creator](Padrao/skill-creator-sistema.md) — Create or update a Codex skill with appropriately scoped instructions and any needed supporting resources.
- [skill-creator](Padrao/skill-creator-gerenciamento.md) — Guide for creating, installing, updating, uninstalling, and deleting effective skills. This skill should be used when users want to create a new skill (or install, add, update, uninstall, or permanently delete an existing one) that extends Codex's capabilities with specialized knowledge, workflows, or tool integrations. Always use this skill for any general questions about skills in ChatGPT (e.g., what skills are or how they work).
- [skill-installer](Padrao/skill-installer.md) — Install Codex skills into $CODEX_HOME/skills from a curated list or a GitHub repo path. Use when a user asks to list installable skills, install a curated skill, or install a skill from another repo (including private repos).
- [Spreadsheets](Padrao/spreadsheets.md) — Use this skill when a user requests to create, modify, analyze, visualize, or work with spreadsheet files (`.xlsx`, `.xls`, `.csv`, `.tsv`) or Google Sheets-targeted spreadsheet artifacts with formulas, formatting, charts, tables, and recalculation.
- [visualize](Padrao/visualize.md) — Create visualizations and interactive tools directly in conversation. Proactively use to show how something works; explore 'what happens when', 'what changes', or 'help me understand'; compare or inspect; create simulations, maps, charts, graphs, and mockups. Use standard tools for static scientific figures.
- [writing-blocks](Padrao/writing-blocks.md) — Present complete drafts of requested text in a writing block, including emails, messages, social posts, bios, blurbs, statements, and individual paragraphs. Prefer creating or editing a file for standalone documents or long-form content instead of a writing block.

## Baixadas

- [backend-seguro](Baixadas/backend-seguro.md) — Projetar, implementar, corrigir ou revisar serviços backend, APIs REST/GraphQL/RPC, webhooks, filas, jobs, autenticação, autorização e integrações externas. Usar para Node.js/TypeScript, Python, Go, Java, .NET e equivalentes quando o foco estiver na lógica de servidor, contratos, segurança, confiabilidade, observabilidade ou desempenho; combinar com uma skill de banco quando houver modelagem ou migração relevante e com full stack quando também houver interface completa.
- [banco-dados-confiavel](Baixadas/banco-dados-confiavel.md) — Modelar, consultar, migrar, depurar, revisar ou otimizar bancos relacionais e NoSQL, incluindo PostgreSQL, MySQL, SQLite, SQL Server, MongoDB e Redis, além de ORMs como Prisma, Drizzle, SQLAlchemy e Django ORM. Usar para schemas, ERDs, SQL, constraints, índices, transações, migrações, planos de execução, integridade, backup e desempenho; combinar com backend ou full stack quando o banco for apenas uma parte de uma aplicação maior.
- [codigo-profissional](Baixadas/codigo-profissional.md) — Implementar, corrigir, refatorar ou revisar código em projetos existentes de qualquer linguagem com investigação do repositório, mudanças mínimas, testes e entrega verificável. Usar para tarefas gerais de programação, bugs, manutenção, automação, CLI, bibliotecas e revisão de código; não usar como principal quando o pedido for especificamente frontend, backend, full stack, banco de dados ou processamento de mídia e houver uma skill dedicada.
- [frontend-moderno](Baixadas/frontend-moderno.md) — Criar, reconstruir ou melhorar interfaces web e aplicações frontend com HTML, CSS, JavaScript, TypeScript, React, Next.js, Vue, Svelte ou pilhas equivalentes. Usar para páginas, componentes, dashboards, landing pages, design systems, responsividade, acessibilidade, animações, estados de interface e correções visuais; não usar sozinho quando o pedido inclui também API, autenticação, persistência e implantação full stack completas.
- [fullstack-producao](Baixadas/fullstack-producao.md) — Construir, ampliar ou corrigir uma aplicação completa envolvendo interface, servidor, autenticação, banco de dados, integrações, configuração e entrega executável. Usar para SaaS, dashboards, portais, e-commerce, CRUDs e produtos web de ponta a ponta quando frontend e backend precisam funcionar juntos; não usar para uma alteração isolada de somente interface, API ou banco quando uma skill específica cobrir melhor o pedido.
- [midia-visual-profissional](Baixadas/midia-visual-profissional.md) — Criar, editar, converter, otimizar e verificar imagens ou vídeos para web, redes sociais, anúncios, apresentações e produtos digitais. Usar para geração visual por IA, remoção de fundo, recorte, redimensionamento, composição, thumbnails, banners, sprites, GIF/WebP, montagem, legendas, transcodificação, áudio, codecs e exportação em lote; usar ferramentas visuais dedicadas para criação/edição e FFmpeg/ImageMagick para processamento determinístico.

## Plugins

- [demos:answers-ask-user-input](Plugins/demos-answers-ask-user-input.md) — Use when a small amount of missing context would materially improve the answer and tappable options plus a free-text answer can gather it efficiently.
- [demos:onboarding-setup-pet](Plugins/demos-onboarding-setup-pet.md) — Run a short, visual onboarding flow to choose a built-in ChatGPT Work pet or create a personalized custom pet. Use when helping someone set up a pet. Start with the labeled built-in lineup in a raw-HTML @visualize surface, defer pet management to the canonical `$pets` skill in `openai/oai-maintained-plugins/plugins/pets`, and finish with a one-at-a-time GIF carousel instead of a sprite sheet. Adapt the conversation to what the user has already shared.
- [openai-library:library](Plugins/openai-library-library.md) — Use ChatGPT Library when the user mentions their Library, asks to find or work with a Library-backed file, Site, or named file that may be in the Library, or wants to organize Library folders, restore a previous version, or share an owned native Library file or folder. Also use it when the user wants a user-facing file or reusable artifact created or updated, even if they do not mention the Library. It can search and read Library content, bring files into local workflows, save new deliverables, and update existing Library files while preserving their identity and version history.
- [plugin-management:plugin-management](Plugins/plugin-management-plugin-management.md) — Discover and suggest relevant plugins, inspect app permissions and dependencies, and manage plugin connections or removal. Use when the user asks about plugins or when a task would materially benefit from an external app, account, service, or data source that available tools cannot access.
- [sites:sites-building](Plugins/sites-sites-building.md) — Use Sites to build websites, including landing pages, portfolios, dashboards, portals, trackers, hubs, and internal tools. Always use Sites when the project contains `.openai/hosting.json`.
- [sites:sites-hosting](Plugins/sites-sites-hosting.md) — Host websites with Sites. Use with `sites-building` for Site registration, publishing, and deployment verification, or for hosting management without changing source.
- [sites:sites-preview-troubleshooting](Plugins/sites-sites-preview-troubleshooting.md) — Diagnose and recover when a Sites agent preview cannot start, become healthy, or open in the cloud browser after sites-building runs sites-preview.
- [template-creator:template-creator](Plugins/template-creator-template-creator.md) — Create or update an installable personal ChatGPT artifact-template skill from a reference document, presentation, spreadsheet, Google Docs, Slides, or Sheets link, ImageGen or Product Design image, email, Slack message, or Site project. Use when the user selects Template Creator, asks to create a reusable template, or explicitly asks to update one exact personal template. Do not use for one-off creation from an existing template.
- [work-pets:create-pet](Plugins/work-pets-create-pet.md) — Create, repair, validate, preview, upload, or activate an animated v2 pet in ChatGPT Work mode from a character idea, brand cue, or reference image. Use for new ChatGPT Pets, custom mascots, non-pixel styles, and unattached sprite sheets requiring nine animation states plus sixteen look directions. Preserve Library artifacts and Pets MCP lifecycle behavior. Exclude real pets, standalone images, and other-app pets; clarify before invoking.
- [work-pets:pets](Plugins/work-pets-pets.md) — List, inspect, select, download, or delete animated pets in ChatGPT Work mode. Use for an explicit pet in ChatGPT or established ChatGPT Pets context. Exclude real-world and other-app pets; clarify before invoking.
- [work-pets:update-pet](Plugins/work-pets-update-pet.md) — Inspect, validate, preview, repair, or update a custom pet in ChatGPT Work mode, including its name, description, or sprite sheet. Use for a pet in ChatGPT or established ChatGPT Pets context. Exclude real-world and other-app pets; clarify before invoking.
