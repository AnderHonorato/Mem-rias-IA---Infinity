# control-browser

- **Origem:** Habilidade padrão disponível no ambiente
- **Disponibilidade:** depende de a habilidade ou plugin correspondente estar instalado no ambiente da IA.

## Finalidade

Control a browser for authenticated or public web tasks requiring live site state or interaction. For selecting a sign-in method or entering sign-in credentials, use only the advertised `browserAuth` capability. For public lookups, use web search first; NEVER fall back to Browser if search fails. Use Browser only when successful search lacks necessary data or direct site interaction is required. ALWAYS prefer applicable plugins; NEVER fall back to Browser if one is unavailable or fails.

## Como usar

Use esta habilidade somente quando a finalidade acima corresponder ao pedido. Antes de agir, leia a versão instalada ou oficial da habilidade no ambiente atual e siga suas dependências, permissões e limites.
