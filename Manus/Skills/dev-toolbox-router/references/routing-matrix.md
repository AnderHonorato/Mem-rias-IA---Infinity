## Critérios de seleção

Priorize skills com `SKILL.md` e frontmatter `name`/`description`, documentação clara, licença identificável, histórico recente e escopo mínimo para a tarefa. A popularidade é apenas um sinal; não substitui revisão de permissões, scripts, hooks, dependências e credenciais. Skills de banco, automação SaaS, fuzzing e publicação exigem autorização e escopo explícitos.

As URLs acima são links de importação do Manus que apontam para os diretórios GitHub auditados. O código e as instruções de terceiros permanecem nos repositórios de origem; a pasta `Manus/Skills/` guarda o catálogo, decisões e snapshots selecionados, não cópias indiscriminadas.
