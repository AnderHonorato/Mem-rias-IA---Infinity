## Regras de importação

Importe uma skill externa somente depois de revisar seu `SKILL.md`, licença, scripts e dependências. Pacotes com banco, automação, fuzzing, publicação, hooks ou credenciais devem ser usados com escopo e autorização explícitos. Não trate uma lista de curadoria ou README como prova de segurança.
