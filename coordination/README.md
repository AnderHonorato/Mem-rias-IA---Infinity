# Coordenação multiagente

Coordenação é transitória e não substitui conhecimento canônico.

- `messages/` — mensagens curtas entre agentes.
- `handoffs/` — transferência estruturada de contexto/tarefa.
- `tasks/` — trabalho pendente ou em andamento.
- `archive/` — coordenação encerrada.

Após concluir uma tarefa, promova somente informação durável para `../knowledge/`.
